In cec-backend, a new mapped column on a SQLAlchemy model and its Alembic migration go in a pull request of their own, merged and deployed before any pull request that reads or writes the column. Review sent back PR 212, which added `Invoice.paid_at` together with the payment webhook that sets it: production ran the new code before the migration, and every invoice query failed until the rollback.
