# An instance starts from at most one package

An instance starts from either kinby's built-in defaults or one package, which may bundle several plugins. Selecting a different package requires a new instance in the first version. Combining or replacing templates would need rules for conflicting prompts, permissions, routines, and existing memory. Updating the selected package remains supported.

Decision agreed during [Package contract and the software factory as the first package](https://github.com/jorgesolerrr/kinby/issues/216).
